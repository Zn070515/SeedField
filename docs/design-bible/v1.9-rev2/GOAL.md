# GOAL — 项目总目标（Full Game）

## 项目定义 [CONFIRMED]

**《种子域》（Seed Field）** 是一款精致二维、系统驱动、可深度编程、具有工业建设和离线文明竞争的 Windows 优先 Steam 付费单机游戏。玩家在主控崩溃后的数字世界中，从“种子”逐步构造自主执行的节点、设备、网络与文明。

**核心体验句：**「设计少数规则，观察大量个体自主行动；发现瓶颈，再通过构造和程序迭代改变整个系统。」

## 产品四大支柱

1. **可编程创造**：真 JavaScript、函数、状态机、消息协议、分布式协同；不退化成预设行为树或参数滑块。
2. **统一规则与系统耦合**：物质、能源、信息、感知、计算、制造和战争不是独立小游戏。
3. **自主涌现与策略深度**：强系统来自部署/协议/网络/局部决策的组合，不靠纯数值堆叠。
4. **可理解的精致表现**：设备、网络、战斗有艺术质感；玩家可追踪个体「知道什么—决定什么—实际发生什么」。

## 面向的玩家

喜欢《The Farmer Was Replaced》《Bitburner》《Turing Complete》《戴森球计划》《Mindustry》《缺氧》一类编程、工程解题、工业系统与优化的人群。[BASELINE] 这些游戏是兴趣和设计参照，不是要求复制其机制或素材。

## 核心承诺 [CONFIRMED]

- 无网也能从新存档玩到一种或多种文明级终局，之后继续沙盒。
- 不会因外部全毁而失去重建机会；核心区永久保底。
- 完成五个最低可用结构即可进入 PvE，代码能力不是入场考试。
- 离线对手的行为遵守同样的世界规则，信息有限，不靠规则作弊。
- 第一场正式战斗目标在开局后 **30–60 分钟**内发生，最终以真人试玩验证。[BASELINE / VALIDATE]
- 一个仿真规则体系支撑自由世界、构造挑战、训练对战、存档与无界面测试。

## 明确不要做成什么

- 不是需要开发者后端的 MMO、永续在线共享宇宙或实时排名赛。
- 不是生物遗传进化、细胞生命繁殖或“AI 觉醒意识”的玩法模拟。
- 不是纯脚本 IDE 或一堆抽象节点线框；建筑、战构体与战争需有可玩性和视觉品质。
- 不是英雄微操 RTS，也不是只靠切换预设策略赢的塔防。
- 不是过度教程化、关卡硬锁阻止玩家自由探索。
- 不是盲目堆砌 100 种元件、几十文明、复杂外交/战略巨构而失去核心闭环的项目。

## 商业与维护原则

- 以真实可完成的单机商品为目标，优先范围纪律和可验证品质。
- 外部作品传播采用文件离线包，Steam Workshop 只作为可选未来分发，不承诺首发上线。
- 内容和对手包必须支持离线安装、离线运行、离线更新；不能将核心功能隐藏于服务条款、账号或 SaaS。

## “完成”的定义 [PROPOSED]

玩家能不依赖网络完成：最低五分支 → 探索与资源增长 → 工坊封装/制造 → 控制器编程与调试 → 自动化产供讯网络 → 防御与进攻 → 对手文明竞争与多区域经营 → 至少一条文明级终局 → 继续自由世界。完整体验应有可恢复失败、可解释调试、足量内置内容、正式视觉音频和稳定存档。
