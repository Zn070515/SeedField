# 术语表 / 中英对照

| 词语 | English / Suggested | 含义与注意 |
|---|---|---|
| 《种子域》 | Seed Field | 产品名称 |
| 种子 | Seed | 主控崩溃后保留最低自主能力的起点；玩家身份载体 |
| 种子核心区 | Seed Core Zone | 玩家永久不可毁的最低复建区，保留五分支产品和低速 E/M |
| 中央主控 | Central Controller（暂译） | 历史统一系统，已崩溃；具体成因与人格性未定 |
| 区域 | Region | 世界的一个真实二维空间块 |
| 区域连接 | Region Connection | 明确跨区移动/物资/供能/信息能力的连接 |
| 自治协议群 | Autonomous Protocol Group | 通过本地规则和网络协作形成的文明雏形 |
| 离线文明版本 | Offline Civilization Version | 其他玩家留下的设备/程序/策略包，导入本地运行 |
| 工坊 | Workshop | 构造、封装、测试设备与产品的平台 |
| 元件 | Component | 具备功能/约束的最低装配单元；未冻结粒度 |
| 模块 | Module | 可重用元件组合，例如供能、通信、火控 |
| 战构体 | Combat Construct（暂译） | 模块化实体，执行移动/战斗/防御任务 |
| 蓝图 | Blueprint | 不可变版本化设计定义；与已部署实例不同 |
| 已部署实例 | Deployed Instance | 真正在世界中拥有位置/库存/损伤的实体 |
| 意图 | Intent | 控制器提出但尚未结算的受限动作请求 |
| 观察 | Observation | 经感知/通信过滤的控制器可见快照 |
| 世界真状态 | WorldState | C# 仿真唯一权威世界数据 |
| 仿真事件 | Event | 真实状态结算结果、故障及表现层输入 |
| 固定 Tick | Fixed Tick | 稳定时间步长推进模拟；频率未冻结 |
| E | Energy | 能源，生产/储存/网络供给/消耗 |
| M | Material（暂译） | 基质，可采集和简化物流运输的物质资源 |
| C | Compute | 算力，设备/分布式程序的游戏内预算 |
| S | Storage | 存储，状态/数据的容量约束 |
| B | Bandwidth | 带宽，数据消息吞吐容量约束 |
| Jint | Jint | 4.18.0 嵌入式 JavaScript 运行时 |
| 文明包 | Civilization Package | 静态可移植的蓝图/程序/策略等数据与可执行内容 |
| 构造关卡 | Construction Challenge | 用验证目标解锁进阶能力的挑战，不阻止基础 PvE |
| 最低可用结构 | Minimum Viable Structure | 五分支教程用的功能性最低标准，不要求高效率 |
| 多终局 | Multiple End States | 多种文明级目标，可在达成后继续沙盒 |
| 宿主预算 | Runtime Safety Budget | 防宿主崩溃的执行限制，区别于游戏 C |

**术语翻译不是正式语言包**，尤其 `Material`、`Combat Construct` 和 `Central Controller` 可以在正式本地化阶段调整。
