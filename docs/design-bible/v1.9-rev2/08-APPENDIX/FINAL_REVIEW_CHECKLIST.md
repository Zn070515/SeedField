# 全游戏方向审核清单（Agent 每轮评审对照）

## 产品

- [ ] Windows 付费 Steam 单机，拔网仍可正常游玩。
- [ ] 无须开发者自己的游戏服务器、账号或云端对手。
- [ ] 足量内置离线文明，不依赖社区作品数量。
- [ ] 玩家所写 JS 对行为有可观察影响，而不是只调参数。
- [ ] 核心玩法跨构造、自动化、建设、文明对抗和长期沙盒，非单纯一张测试地图。

## 教程与工坊

- [ ] 能源、感知、通信、状态、执行五个最低可用结构全部有明确验证。
- [ ] 最低质量合法结构仍可通过，教程后立即进入 PvE。
- [ ] 高级 AND/OR 不追溯锁住自由世界。
- [ ] 设计/蓝图与已部署实体版本不同步；升级要明确操作。
- [ ] 工坊、JS 编辑默认暂停，用户能主动实时运行。

## 世界与经济

- [ ] 多区域中的每区具有真实二维位置与导航。
- [ ] 区域间实体/物资/能源/消息必须遵守明确连接和时序。
- [ ] E/M 是库存，C/S/B 是容量或预算而非无根源货币。
- [ ] 通信/感知受限，AI 不能偷看不可见敌人。
- [ ] 战斗与 UI 共享仿真内核，渲染不决定胜负。

## 核心区与失败

- [ ] 核心区始终不可摧毁，保留原始种子与最新五分支产品。
- [ ] 核心区极低速、不可切断 E/M 保底再生。
- [ ] 玩家外部所有资产可以失去，但总有可行复建路径。
- [ ] 保底资源不能无条件用于免费大规模工业与无限高级机体复制。
- [ ] 程序错误、运输封锁、旧版迁移不会造成永久软锁。

## 文明与终局

- [ ] 对手源自玩家离线版本，在本地自主响应当前局势，而不是固定录像。
- [ ] 对手初始/运行信息和资源必须受统一规则约束。
- [ ] 多文明能在玩家不主动操作时继续产生合法变化。
- [ ] 多种文明级终局，完成后仍可继续沙盒。
- [ ] 其他文明核心区是否不可毁仍明确标记 OPEN，不偷设答案。

## 质量与工程

- [ ] C#（.NET 10.0）+ Godot 4.7.2 .NET + Jint 4.18.0 精确版本可实际构建运行。
- [ ] 真正有安全/预算的脚本宿主；第三方 JS 未满足强隔离前不开放执行。
- [ ] 固定种子/相同环境的无界面模拟可复现。
- [ ] 蓝图、存档、程序和离线包格式版本化并可迁移。
- [ ] 精致 2D、美术完成度、场景截图、音效和可读 UI 达商品要求。
- [ ] Roadmap 到发布与维护，但研发只按已验证的最小可玩切片推进。
- [ ] 未执行的测试绝不标记为已通过；所有完成结论有运行证据。
