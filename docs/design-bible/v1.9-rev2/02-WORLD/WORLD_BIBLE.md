# 世界观总纲 — 崩溃后的数字世界

> **世界观提案稿。** 以下“主控崩溃—节点幸存—种子形成文明”的主轴属于既有共识；年代、地名、古文明名称、具体灾难成因、中央主控是否有人格等均未冻结，不得编造为正式史实。

## 世界本质 [BASELINE]

这不是现实地球，也不是用于逼真模拟生物细胞繁殖的显微世界。这里是一片拥有**真实二维空间**与**连接式计算网络**的数字环境。实体可以占据位置、存储状态、感知局部、通过链路通信、消费能源与材料，并执行有成本的行动。

在遥远的过去，世界曾由某种统一的中央主控系统组织。主控失效后，跨域协调瓦解，大型网络碎片化，大量计算节点进入休眠。仍保存最低能源、执行能力和状态的节点没有彻底消失，它们成为重新生长的**种子**。

许多自治协议群在长期隔绝和资源竞争中演变为风格不同的数字文明。玩家进入游戏时，中央主控已经崩溃很久，世界中存在成熟的文明与遗迹；玩家不是第一批复苏的种子。[CONFIRMED Rev2 Q6 B]

## 玩家是谁

玩家是**系统设计者/协议设计者**，而非无条件获知全图的神明。玩家的权力来自自己能部署的设备、程序、网络与资源：

- 想知道远处发生什么，需要侦察、传感器或可信的通信。
- 想让设备持续行动，需要能源、可执行逻辑与有效执行器。
- 想控制远处队伍，需要遵守通信和部署约束。
- 想改进军队，需要改造真实机体、程序和协作模式。

## 种子核心区 [CONFIRMED]

玩家拥有永久存在且不可摧毁的**种子核心区**，保有种子及能源/感知/通信/状态/执行五个分支的最新已确认架构产品。它以极低速率再生不可切断的基础能源 E 与基质 M，赋予玩家永远可行的重新建设路径。它是世界规则中的明确不对称保护，不应在剧情中悄然弱化。

**世界观解释尚未冻结 [OPEN]**：它可以是主控遗留的隔离分区、世界安全协议、底层只读保护域等，但不要擅自宣布具体真实来源。核心区“绝对不可摧毁”是一条游戏规则，不应靠可被敌方破解的普通护盾解释。

## 多区域世界 [CONFIRMED]

世界不是一张无限无缝大平面。它由多个彼此连接的区域构成，每个区域内是真实可移动、可战斗和可部署设施的二维空间；区域连接可能承担实体运输、资源物流、能源输送或信息通信，但每类能力需要明确约束。

开发者可通过手工设计关键区域和约束下的半程序生成扩展探索性。[BASELINE] 玩家世界里的其他文明会在本地独立发展，不是等待玩家触发的静态刷怪点。[CONFIRMED]

## 文明的来源与冲突

不同种子/自治协议群在长期发展中形成不同的控制协议、发展偏好、资源禀赋与部署架构。它们可以合作、竞争或战争，其差异来自**行为系统与局部条件**，不应全靠颜色、数值倍率或人为作弊。[CONFIRMED Rev2 Q5 B]

游戏中 PvE 对手的**产品来源**是其他玩家留下的离线文明版本，包括内置的作者型对手和未来可导入的玩家文明包。包由游戏本地仿真执行，原作者不需在线。**这是世界运行的实现方式，不要求在世界观中把每个对手都直接写成“现实世界另一个玩家”。** 是否使用“远方协议残响/文明镜像”等叙事包装是待定文本选择。[OPEN]

## 叙事风格 [BASELINE]

轻剧情、强环境叙事。通过遗迹、旧协议、损坏设施、敌对模式、失落网络和文明行为让玩家推测历史；避免大型强制对白、连续剧情演出、必须观看才能玩懂的开场长片。世界观应帮助玩家理解系统为何存在，而不是替代系统玩法。

## 主题关键词

**失联 / 重建 / 分布式 / 余烬 / 协议 / 自主 / 冗余 / 进化（工程意义） / 边界 / 文明竞争**。

“进化”在本游戏中主要是设计、部署、程序与组织机制的迭代优化，**不是生物基因遗传、细胞繁殖或模拟人格意识**。

## 世界设定空白 [OPEN]

- 中央主控的具体成因、性质及能否被重建；是否与终局有关。
- 种子核心区不可摧毁的世界内合理化方式。
- 区域的命名体系、地图风格、完整地理规模。
- 文明数量、代表文明历史和交往方式。
- 多文明终局的实际故事对象和世界状态变化。
