# 不可摧毁种子核心区：永久存续、保底经济、战败

## 最高优先级确认规则 [CONFIRMED]

1. 玩家拥有一个**不可被摧毁的核心区**，不受外部战斗破坏。
2. 核心区保存原始种子及能源、感知、通信、状态、执行**五个基础分支最新已确认架构的产品**。
3. 核心区拥有**极低速、不可被切断**的基础 E/M 资源再生能力（用户已选 B）。
4. 外部设施、库存、战构体、网络和领地可全部损失，仍能**随时启动复建过程**。
5. 游戏永远不能把玩家卡在“没有任何合法重建操作”的状态；这一点是核心体验保证。

## 概念模型 [PROPOSED]

核心区可以提供三个不同职责：

- **永久知识/产品登记**：种子、五分支当前确认版本和必要依赖信息，保留历史兼容与恢复落点。
- **有限保底再生器**：低速生产基础 E/M，采用严格容量/吞吐/使用边界。
- **引导复建入口**：即便外部供能、通信、工厂和常规库存都消失，也能制造/恢复最低可用五分支链路并部署最初设备。

真正的五分支“最新产品”具有产品形态并应可恢复；它的制造成本与“最低复建保障”之间需有清晰模型，防止高级设备免费无限复制。

## 重要边界与反利用 [OPEN / PROPOSED]

- **库存与速率**：需要通过试玩确定；此前举例的 E/s、M/s 数值都非批准平衡数据。
- **无限资源套利**：低速无限期再生确实意味着无限时间可积累。建议将其作为仅支持复建的、有限吞吐的保底配额，不成为无限规模工业输出源。
- **无法离开核心区**：敌方长期封锁所有出口可能造成实际软锁。需要保底的部署逃生、多个出口、保护缓冲区或可突破机制（未定）。
- **程序全坏**：若玩家“最新五分支产品”的控制程序失效，必须存在可执行的最低引导版本/安全回退，不因玩家的一次错误永久锁档。[PROPOSED]
- **敌方核心区**：未确认是否同样绝对不可摧毁。不得自动冻结公平对称假设。

## 战败是什么

- 外部战争失败：资源损失、设备损坏、区域撤退、工业与通信受损；不是强制删除存档。[CONFIRMED]
- 核心区存在确保最低延续；不保证立刻重新获得外部最高科技或军团。[CONFIRMED+PROPOSED 解释]
- 军事结果需要可量化的局部/区域目标，不能用“敌人的核心无法炸掉”导致永远没有胜者。[PROPOSED]

## 强制可恢复性不变量

> **任一合法世界状态中，玩家从核心区能够在有限且可观察的操作链内恢复至少一个可执行最低行动的实体。**

注意：这个更严格的“有限操作链”是为了落实用户的“随时可以复建”而提出的工程验收命题；具体等待时间上界/成本是待测参数，不应假称已确认。

## 必测极端场景

- 所有外部库存=0，所有工厂/通讯节点/电厂/军队损毁；
- 保底 E/M 当前库存=0（等待再生后可以继续）；
- 最新设计过于昂贵、无法在基础阶段生产；
- 用户 JS 编程死循环/权限异常/状态文件损坏；
- 所有核心区出口长期遭敌方封锁；
- 游戏存档从旧蓝图 schema 迁移后，最新五分支版本仍可恢复。

所有场景应满足“不会无解地卡死”；对应的变通机制和数值要经过产品批准/试玩。
