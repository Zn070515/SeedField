# 视觉风格与技术美术

## 已确认方向 [BASELINE]

**精致 2D + Blender 预渲染 + Shader** 是基准方向；需对比分层精灵、低模 Blender 预渲染及少量 GPU 特效的真实开发成本。设备/设施强调轮廓、体积和材质，网络、能量、信号、护盾、命中则强调动态光流和反馈。

不能以简单 SVG 圆点/线框/棋盘演示图替代正式付费游戏的视觉素材。早期原型可用占位图验证机制，但不能把占位图当成验收完成。[BASELINE]

## 视觉语言 [PROPOSED]

- **世界层**：冷静、工业感的数字地形、区域连接和遗迹；空间层级清晰。
- **设备层**：高辨识度轮廓和模块安装位，远看区分功能，近看有材料质感。
- **网络层**：能源流、信息流、带宽拥堵和断联以不同图形语言表达；不仅靠颜色区分。
- **战斗层**：发射、弹道、盾击、模块失效有瞬时可读反馈。
- **核心区**：和普通基地明显不同，强调永久稳定、少量资源再生与五分支保留状态。

## 不能让视觉误导规则

- Shader 光束不是物资/能量真实传递的判定依据；视觉只表现仿真事件。
- 粒子不决定命中；战斗和通信实际因果必须可独立在 Headless 下验证。
- 不展示程序/传感器不应知道的敌人精确位置；可以有不泄密的未知威胁提示。
- 一眼能辨别电力断开、消息丢失、过载、控制器异常和资源运输阻塞。

## 先制作的基准样片 [VALIDATE]

1. 一台美术完成度合格、模块可替换的战构体：远/近景。
2. 一段从供能/通信节点延伸的网络，状态变化真实可视。
3. 一种武器与护盾命中，含故障/断供反馈。
4. 一个有限区域内 10–50 台设备的可读性与 GPU 成本试验。
5. 一张含真实截图的工坊/程序调试布局，而不是概念图。

## 制作管线 [PROPOSED]

`Art Bible → Blender/2D 源资产 → 导出/分层 → Godot 材质/Shader → 仿真事件驱动动画 → 截图与性能回归`。

源文件、导出脚本、资源来源与许可证应保留，方便 Agent 反复生成变体与回归检查。
