# CHANGELOG — 本设计资料包

## V1.9 Rev2 全游戏资料汇编 — 2026-11-16

- 以当前最新用户决策整理全游戏世界观、玩法规则、资源、五分支、编程、核心区、PvE 离线文明与多终局。
- 将原 M0-only 工程说明提升为覆盖商业正式版生命周期的完整设计资料包，包含 M0–M8 路线、质量、安全、Steam 发布要求和 Agent 交接。
- 明确旧版 Lua/Luau 技术讨论已被 JavaScript/Jint 4.18.0 取代。
- 固定不运营开发者服务器的架构前提，绝不要求在线对手、实时匹配或云端存档才能体验完整游戏。
- 加入“已确认/历史共识/待验证/建议/开放”标签，防止推荐细节被误当用户批准。
- 加入系统测试矩阵、风险登记、未决 ADR 及全游戏场景验收样例。

## 后续维护要求

每次用户明确决定应新增 Change 条目，包括影响的规则 ID、文件、数据 schema、存档迁移风险和实际测试证据。设计档案版本不一定等于软件构建版本。
