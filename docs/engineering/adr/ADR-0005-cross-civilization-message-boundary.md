# ADR-0005：跨文明消息的协议边界

- 状态：**Accepted（原型语义）**
- 日期：2026-11-17
- 关联决策：D-01、O-01、SCENARIO S3/S9

## 背景

跨文明消息现在已经可以发送，但只有“目标文明在目标区域有 Comm 端点”这一条约束。设计需要外交、情报权限、协议和断联对抗，这些尚未冻结。

## 决定

当前原型只保证：

1. 发送者必须有 `Comm` 模块；
2. 目标文明在目标区域必须有 `Comm` 端点；
3. 消息按链路延迟进入**目标文明**收件箱，不进入发送者收件箱；
4. 设备观察只看到自己所在区域的消息；
5. 没有身份认证、条约、话题 ACL、消息签名或第三方包权限。

不把“能发消息”误称为完成外交/情报系统。

## 后果

- 可以验证跨区/跨文明通信的基本时序与信息隔离。
- 任何文明只要发现目标区域和端点就可以发送消息；这在正式游戏中需要协议层/拒绝策略/情报权限。
- 第三方可执行包仍然关闭；消息内容不会自动获得执行权。
- 后续加入协议层时必须：
  - 定义消息话题/能力声明与拒绝语义；
  - 保持设备级观察；
  - 为断联、伪造与重放写回归测试。
