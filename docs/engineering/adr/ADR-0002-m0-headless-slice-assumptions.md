# ADR-0002：M0 Headless 切片的简化假设

- 状态：**Accepted（仅限原型，不是商业最终规则）**
- 日期：2026-11-16
- 关联决策：G-06、G-07、E-02、R-01、R-02、O-01

## 背景

首个纵切片需要证明“真实 JS 控制器 + 统一仿真 + 可复现事件”可行，同时避免在未冻结的设计项上做不可逆决定。

## 决定

1. **整数坐标**：位置、速度、射程以毫米整数表示，移动使用整数插值，完全避免浮点。
2. **固定动作成本**：移动、开火、发信各按配置的固定 E 成本结算；不按距离/功率建模。
3. **同文明消息**：当前只允许发往发送者所属文明；跨文明通信等待拓扑与带宽设计。
4. **直接命中**：无随机命中率；武器在射程内立即造成固定伤害。
5. **死亡移除**：生命值 ≤ 0 的实体立即从区域移除，后续意图返回 `UnknownEntity`。
6. **核心区复建 API**：`TryBootstrapFromCore` 是用于验证“外部全毁仍可复建”的脚本化入口，不是正式建造流程。
7. **无 RNG**：本轮没有随机数消费者，因此世界状态不含 RNG；引入随机性前必须先加入可哈希的确定性随机状态。
8. **单区域**：所有实体位于同一区域；多区域与跨区因果留待下一阶段。
9. **观察携带全部已投递消息**：本轮 inbox 无容量上限，消息会持续累积；正式实现必须加入 S 容量、分页/裁剪与确定性保留策略。

## 后果

- 切片可运行、可复现、可测试，但它不是玩法平衡结论。
- 正式产品必须重新评估动作成本、命中模型、消息路由、死亡资源结算与核心区配额。
- 若未来改动这些假设，需更新此 ADR 并补充回归测试。
