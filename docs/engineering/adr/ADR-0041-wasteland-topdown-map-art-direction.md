# ADR-0041：世界层美术改为废土正交俯视地块地图

- 状态：**Accepted（方向确认；资产仍为样片）**
- 日期：2026-11-18
- 关联决策：A-01、A-02（2026-11-18 用户明示）
- 替代：ADR-0024 的“世界层 35° 斜俯视”选择；ADR-0025 的 8 方向立面帧不再是默认要求

## 背景

Gate 2/3 的世界样片采用 35° 斜俯视：Blender 立面渲染、设备有高度和机械立面、
地形是冷灰蓝工业底板。用户明确要求改为 **Mindustry 式地图 + 末日废土感**：

- 严格正交俯视，而不是斜俯视立面；
- 资源直接以矿脉铺在地表，使资源分布和 PvE 目标在同一张地图上自然可读；
- 锈蚀、焦土、沙尘、灰烬与残骸是默认语言；干净的高科技外观不再代表世界。

现有斜俯视资产（8 方向工体、带立面的电力塔/核心）与新方向不兼容；继续生产会
放大返工成本，因此先冻结方向并给出可运行样片。

## 决定

### 1. 世界层美术契约

- 相机：严格 90° 俯视；世界坐标仍由 `Camera2D` 平移/缩放，HUD 固定在 `CanvasLayer`。
- 基准网格：样片 64 px 地块；正式尺寸与最低缩放可读性后续实测。
- 地表：至少四类地貌（焦土/沙地/灰烬/锈蚀）+ 碎石、裂缝、残骸与焦痕；用大区块
  区分地貌，而不是全图统一底色。
- 资源：铜/铅/钛/煤等矿脉直接画在地块上，颜色 + 形状双重区分；后续接入真实
  区域资源分布时，地图层只读仿真/场景数据。
- 建筑：地块占位、块状轮廓、厚暗边、锈蚀金属底色；少量暖色状态灯表示工作状态。
- 种子核心：唯一保留“仍在运行的科技”观感的对象，作为废土中的对比焦点。
- 单位：俯视剪影 + 旋转；不再要求 4/8 方向立面帧。
- 光影：以贴地接触阴影和局部发光为主，不使用斜向长投影模拟建筑立面。

### 2. 与仿真的边界

- 美术层只读 `Observation` / `SimulationEvent` 或场景配置；资源图标不自行决定库存。
- 本 ADR 不改变 Tick、坐标、存档、哈希、Jint 或离线包契约。
- 地图上的资源显示必须与真实区域库存/矿脉配置一致；禁止用贴图暗示不存在的资源。

### 3. 迁移顺序

1. 风格样片：`Scenes/MindustryStyle.tscn` + 程序化地块/矿脉/块状建筑，先验证可读性。
2. 地形层：用正式地块资产替换 `WorldBackdrop`，保留现有网络/事件层。
3. 设备层：把工体/核心资产重制为正交俯视块状版本；斜俯视资产降为历史参考。
4. 资源与 PvE：按真实区域配置绘制矿脉、敌方基地与威胁标记。
5. UI：资源条、选中信息、建造/工坊面板统一为废土色板。

## 非目标

- 不把样片标记为正式美术；`status` 仍是样片。
- 不在本 ADR 实现资源分布、PvE 生成或新的世界拓扑。
- 不删除 ADR-0024/0025 的资产与门禁；它们保留为历史对照和回归证据。
- 不决定最终地块像素、调色板、最低配置或 Shader 预算。

## 后果

- 世界层资产需要重制；已完成的 8 方向工体与斜俯视立面不再作为主路径。
- 地块/矿脉让“资源在哪、为什么争”直接可见，为后续资源分布与 PvE 关卡提供
  统一视觉语言。
- 单位朝向帧成本下降；地形/装饰资产量上升。
- 需要新增资产门禁：地块无缝、矿脉可读性、最低缩放下的建筑辨识度。

## 验证

- `dotnet build game/SeedField.Game/SeedField.Game.csproj` 通过。
- `godot --path game/SeedField.Game res://Scenes/MindustryStyle.tscn -- --capture-art`
  输出 `screenshots/art-mindustry-style.png`。
- 样片需能在截图中同时读出：四类地貌、四种矿脉、玩家/敌对建筑、旋转单位与资源条。

## 回滚

删除样片场景/脚本与 ADR-0041 即可回到 ADR-0024 的斜俯视样片；不影响仿真、
存档或测试门禁。
