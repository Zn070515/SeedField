# ADR-0004：区域活动与离屏模拟边界

- 状态：**Accepted（原型语义）**
- 日期：2026-11-16
- 关联决策：W-02、O-01、路线图 M3

## 背景

设计允许离屏区域采用精度简化，但要求加载/卸载不改变资源、事件顺序与可复现性。当前没有分区 Tick 预算或增量加载。

## 决定

- `SimulationEngine` 的 active/inactive 是**会话状态**，不写入世界存档、不进入哈希。
- 非活动区拒绝控制器意图（`RegionInactive`）；消息/物资/能源投递、核心再生等全局被动系统继续运行。
- 被动**发电**按区域跳过，并在激活时按 `World.Tick - 停用Tick` 补算；开关区间内没有意图，补算后状态与全程活动一致。
- 保存前必须 `CatchUpInactiveRegions()`，避免把未补算的电网状态写进存档。
- 仍不实现完整的分区 Tick 预算/增量加载；当前只优化了非活动区的发电结算。

## 后果

- 当前 active 标记是语义/权限切片，不是性能优化；不得宣称 M3 离屏优化完成。
- 活动/非活动被动运行的状态哈希一致，有回归测试。
- 未来若引入分区 Tick 预算，必须：
  1. 明确 pending tick 是否进入世界状态与存档；
  2. 提供加载/卸载/跨区事件的顺序回归；
  3. 禁止用视角切换刷资源或重置敌人。
