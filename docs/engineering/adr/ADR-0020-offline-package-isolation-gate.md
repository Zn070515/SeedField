# ADR-0020：离线文明包隔离门禁与威胁模型

- 状态：**Accepted（架构方向）；导入仍关闭**
- 日期：2026-11-17
- 关联决策：D-02、D-03、P-02、O-01
- 前置：ADR-0005、ADR-0018

## 背景

D-02 要求 PvE 对手来自其他玩家的离线文明版本，但 AGENTS 硬约束明确：

> Jint 的语句/内存/超时限制属于降级防护，不是 OS 沙箱。未实现进程隔离、IPC 校验与
> 资源限额前，禁止开放任意第三方可执行包导入。

当前实现只运行内置 `builtin.*` 包；`OpponentPackage` 只做内存中的元数据/路径/大小/
schema 校验，没有文件导入 API。数据-only 废墟快照（ADR-0018）不是可执行包。

本 ADR 固化威胁模型、目标隔离架构与开放导入前的硬门禁。

## 决定

### 1. 当前门禁保持关闭

- `OpponentPackage.ThirdPartyImportEnabled = false` 是**代码常量**，不是 UI 开关。
- 仓库 Lint 要求对手包命名空间不出现文件/网络/进程/程序集加载 API。
- 只允许内置受信任包；第三方可执行包导入/执行继续关闭。
- 数据-only 快照（废墟）可以继续使用：它不执行代码，只生成残骸。

### 2. 目标隔离架构

采用**父进程权威 + 不可信工作进程**：

- 父进程持有世界状态、RNG、Tick、存档；工作进程只接收过滤后的 `Observation`
  和预算，返回 `Intent`。
- 每个不可信包一个工作进程（粒度可按性能再评估）。
- Windows 优先：Job Object（内存/CPU/进程数/强杀）、受限令牌/低完整性/AppContainer、
  无网络能力、只读包目录、独立临时目录、无继承句柄。
- IPC：长度前缀帧、版本化消息、大小上限、请求 ID/Tick、超时、严格解析、fuzz。
- 确定性：不使用真实时钟/系统随机；父进程回放并比对 Intent 哈希。
- 包格式：签名清单 + 数据/JS 文件；无原生二进制；总大小/文件数/解压比/路径限制。
- 失败关闭：超限/崩溃/协议错误 → 终止工作进程，本局不再调用该包，世界继续。
- 审计：包 ID/版本/哈希、拒绝原因、预算、违规、退出码。

详细威胁表、信任边界与测试矩阵见
[`docs/engineering/security/2026-11-17-offline-package-threat-model.md`](../security/2026-11-17-offline-package-threat-model.md)。

### 3. 开放导入的硬门禁

必须全部通过：

1. 进程隔离 + Job Object/AppContainer 自动化测试；
2. 网络访问被 OS 拒绝；
3. 文件系统只读/空临时目录 + 路径穿越/符号链接/TOCTOU 测试；
4. CPU/内存/磁盘/进程数限额 + 强杀测试；
5. IPC fuzz（超长/截断/乱序/重复/非法 UTF-8/未知字段）；
6. Jint/原型链/构造器/宿主对象逃逸测试；
7. 确定性回放与分叉告警；
8. 签名/哈希/允许清单/能力校验；
9. 用户显式授权与“未受信任”标签；
10. 包缺失/版本不符时安全降级；
11. 审计日志与崩溃/重启策略；
12. 独立安全审查。

任一条未完成，`ThirdPartyImportEnabled` 保持 `false`。

### 4. 分阶段

- **Phase 0（当前）**：内置包 + 数据-only 废墟；门禁常量 + 仓库 Lint。
- **Phase 1**：工作进程/IPC/限额；仍白名单。
- **Phase 2**：签名包与显式用户授权；本地文件分发，Workshop 可选。
- **Phase 3**：多包并发/跨平台/红队。

## 非目标

- 在本 ADR 中实现完整工作进程/IPC（Phase 1 单独实现）。
- 允许第三方原生二进制、安装脚本、网络访问或自动更新。
- 在线账号/匹配/云推理；仍坚持 P-02。
- 为废墟快照增加可执行内容；快照保持数据-only。

## 后果

- 当前版本继续只运行内置对手；玩家不能导入第三方可执行包。
- 威胁模型与门禁可被后续实现逐项勾选，避免“先开放再补安全”。
- 仓库 Lint 会在有人误加文件/网络/进程 API 到对手包命名空间时失败。
- 数据-only 废墟可以离线分享，不引入执行风险。
