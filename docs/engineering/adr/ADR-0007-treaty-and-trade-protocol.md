# ADR-0007：条约与贸易协议（原型语义）

- 状态：**Accepted（原型语义）**
- 日期：2026-11-17
- 关联决策：D-01、O-01、OPEN-10
- 前置：ADR-0005、ADR-0006
- 后续：ADR-0008（对手外交响应策略）

## 背景

ADR-0006 只提供无状态的入站消息 ACL，没有条约、关系或资源交换。OPEN-10 的外交/贸易范围仍未冻结；本轮由用户明确要求做“条约/贸易协议”，因此实现一个**可替换、最小但有真实规则效果**的原型：

- 互不侵犯条约必须真的阻止攻击；
- 贸易协定必须真的允许跨文明材料/能源交换；
- 权限与资源必须可审计、可复现、可回滚。

不把本 ADR 当作正式外交系统或最终平衡。

## 决定

### 1. 条约种类与权限

| 种类 | 效果 |
|---|---|
| `NonAggression` | 生效期间，双方互相攻击在扣能量前被拒绝 |
| `Trade` | 允许双方创建/接受贸易单 |

- 所有签约、响应、撕毁、贸易下单/接单/取消都只能通过宿主 `ExecuteDiplomacyCommand`。
- 设备脚本只读取观察、发送普通消息；不能替文明签约或动用区域库存。
- 条约是双边的；同一对文明同一种类最多一个生效条约和一个待处理提议。

### 2. 提议与生效

- `ProposeTreatyCommand` 创建待处理提议，带 `ExpiresTick`。
- 提议方与目标方必须有通信路径：双方都有 Comm 端点，且同区或经链路可达。
- 目标方通过 `RespondTreatyCommand` 接受或拒绝；响应同样要求通信路径。
- 提议到期自动移除；不产生条约、不转移资源。
- 重复提议返回 `TreatyExists`；不存在的提议/非目标方响应返回 `ProposalNotFound`；不存在的条约/非当事方撕毁返回 `TreatyNotFound`。
- 撕毁 `BreakTreatyCommand` 是单边行为，不要求通信路径；立即移除条约。
- 新增错误码：`TreatyDenied`、`TreatyExists`、`TreatyNotFound`、`ProposalNotFound`、`TradeNotFound`。

### 3. 互不侵犯的强制执行

- `ProcessAttack` 在目标可见性校验之后、冷却与能量检查之前检查条约。
- 若攻击方与目标方存在生效的 `NonAggression`，返回 `TreatyDenied`，不扣能量、不进入冷却、不产生伤害。
- 撕毁后攻击立即恢复；不追诉撕毁前已结算的攻击。

### 4. 贸易单与托管

```text
TradeOffer {
  Id, Proposer, Target, RegionId,
  GiveMaterial, GiveEnergy, WantMaterial, WantEnergy,
  ProposedTick, ExpiresTick
}
```

- 只有存在生效 `Trade` 条约时才能创建或接受贸易单。
- 创建时立即从**指定区域**的提案方库存扣除并托管 `GiveMaterial`/`GiveEnergy`；任一不足则整单失败，不做半扣。
- 接受时先校验目标方库存；再一次性扣除 `WantMaterial`/`WantEnergy`、把托管物给目标方、把目标方支付物给提案方。任一不足则不改变库存，贸易单保持有效。
- 拒绝、提案方取消、到期都全额退款给提案方。
- 撕毁 `Trade` 条约时，级联取消双方未完成贸易单并退款。
- 结算只发生在单个区域；跨区运输仍由现有物流系统承担，贸易不免费搬运。

### 5. 生命周期与可复现

- 提议与贸易单在 Tick 边界按 ID 稳定顺序过期；宿主命令执行前也先清理已过期状态。
- 新增稳定 ID 计数器与集合，全部进入世界哈希和存档。
- 世界存档 schema v6 → v7；旧存档补空集合与零计数器。
- 新增统计：`TradeMaterialSettledTotal`、`TradeEnergySettledTotal`。

### 6. 观察

- 文明级观察新增 `treaties`、`treatyProposals`、`tradeOffers`。
- 条约与提议按“己方是当事方”过滤；设备观察中的贸易单再按设备所在区域过滤。
- 观察只读；不暴露其他文明的条约、提议或贸易单。

## 非目标

- 消息驱动谈判、延迟投递的条约提议。
- AI 自动接受、信誉、关税、制裁、情报共享、同盟。
- 条约期限续签、违约惩罚、战争状态机。
- 跨区域贸易物流、贸易税/手续费。
- Godot 外交面板（下一批）。

## 后果

- 条约有可验证的规则效果，而不是纯标记。
- 托管让“接受时资源不足”不会造成单边损失，但会占用提案方库存直到成交/退款。
- 宿主独占外交权限是安全边界；未来若要设备自动外交，必须新增授权模块与额度，并写新 ADR。
- 单区域结算避免了与物流系统耦合，但也意味着玩家需要自己把货物运到交易区域。
